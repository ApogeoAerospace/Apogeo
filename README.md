## Branching Model

This project uses a branch-based development model:

- **main**: This branch contains production-ready code. All development should be done in other branches.
- **develop**: This is the main development branch. All feature branches are created from develop and merged back into it.
- **feature/\***: Feature branches are used for new development. They are branched from `develop` and merged back into `develop` via pull requests.

For more details, see the `CONTRIBUTING.md` file.
