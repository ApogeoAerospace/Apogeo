Detailed Description

Propulsion plugin

The propulsion plugin is currently in its architecture and interface-definition phase. Its design separates the host ABI, state/configuration mapping, propulsion orchestration, engine models, and propellant storage.

Design deliverables

  • Architecture
  • Editable UML source
  • Rendered UML diagram
  • Initial C++ interfaces
  • Initial model hierarchy
  • Host boundary adapter

No production propulsion implementation is introduced by this task. The headers define the intended contracts for the implementation and test phases.
