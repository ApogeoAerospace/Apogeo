# Resumen de roadmap

Este roadmap rastrea funcionalidades planificadas que aún no están totalmente implementadas.

## Orden de prioridad

1. Integración de configuración del núcleo
2. Validación + controles de logging/pipeline
3. Plugins de ambiente + aerodinámica
4. Plugin de propulsión
5. Plugin de estructuras
6. Integración de modelos de misión/vehículo

## Definición de terminado

Un ítem del roadmap está completo cuando:
- el parseo está implementado,
- la integración en runtime está implementada,
- se agregan pruebas (GTest + integración),
- la documentación vigente se actualiza.
