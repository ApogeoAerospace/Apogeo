# Scripts

Cross-platform helper scripts for MoLab.

## Dependency check
- macOS/Linux: `./scripts/install_dependencies.sh`
- Windows (PowerShell): `./scripts/install_dependencies.ps1`

## Launch web interface
- macOS/Linux: `./scripts/launch_web.sh`
- Windows (PowerShell): `./scripts/launch_web.ps1`

## Local CI smoke pipeline
- macOS/Linux: `./scripts/test_ci_pipeline.sh`
- Windows (PowerShell): `./scripts/test_ci_pipeline.ps1`

## Removed obsolete scripts
- `scripts/demo_complete.sh`
- `scripts/test_realistic_scenarios.sh`

They were removed because they depended on outdated paths/configurations and no longer match the current repository structure.
